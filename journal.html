Setting up the site

Summary

Laurel set up a simple static website to translate the Ordinary Time sketch from Figma into a responsive page: a single index.html showing Ordinary Time in Garamond No. 8 italic, centered on the screen, on a forestgreen background with green text.

The type is sized in viewport units (12.5vw), so the phrase scales with the window instead of breaking at fixed sizes. The page doesn't scroll and ignores clicks: it's for looking at.

The fonts are self-hosted, and jQuery and an empty script.js were ready for the logic to come. The first commit, "up", was pushed to GitHub (laurelschwulst/liturgical-calendar) at 2:45 pm.
